# SANTAMESIAS Studio 🎵🎚️

**Análisis Musical Profesional 100% Offline para Productores y DJs**

Herramienta web de vanguardia que analiza audio directamente en tu navegador. Sin servidores, sin internet, máxima privacidad y precisión profesional.

##  Características Principales

-  **Detección de BPM:** Algoritmo avanzado Onset + Autocorrelación
- 🎹 **Análisis de Tonalidad:** Krumhansl-Schmuckler Key Detection
- 📊 **Espectro en Tiempo Real:** Bajos, Medios y Agudos
- 📈 **Perfil Tonal Total:** SVG dinámico estilo Mastering Analyzer
- 🔊 **Reproductor Integrado:** Waveform interactivo con scrubbing
-  **Historial Local:** Guardado automático en navegador
- 🚫 **100% Offline:** Todo se procesa localmente

## 🛠️ Tecnologías

- HTML5 / CSS3 (Glassmorphism + Animaciones)
- JavaScript ES6+ (Web Audio API + Canvas API)
- Cero dependencias externas

## 📥 Uso

1. Abre `index.html` en Chrome, Edge o Firefox
2. Arrastra tu archivo de audio (MP3, WAV, FLAC, OGG, M4A, WEBM)
3. ¡Analiza al instante!
